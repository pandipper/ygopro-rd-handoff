## 2. MDPro3 的"本地 AI 对战"实现链路

### 2.1 入口：`SoloSelector.LaunchWithConfig`

`src/MDPro3/Assets/Scripts/MDPro3/Servant/SoloSelector.cs`

```csharp
private void LaunchWithConfig(string command, int duelPort, int duelLp, int duelHand, int duelDraw
    , bool lockHand, bool noCheck, bool noShuffle)
{
    port = duelPort.ToString();
    string lp = duelLp.ToString();
    string hand = duelHand.ToString();
    string draw = duelDraw.ToString();
    string args = port + " -1 5 0 F " + (noCheck ? "T " : "F ") + (noShuffle ? "T " : "F ")
                + lp + " " + hand + " " + draw + " 0 0";
    if (TcpHelper.IsPortAvailable(duelPort))
    {
        YgoServer.StartServer(args);                    // ① 进程内启动 YGOPro 服务器
        RoomServant.FromSolo = true;
        ...
        TcpHelper.LinkStart("127.0.0.1", Config.Get("DuelPlayerName0", ...), port, string.Empty, true,
            () => StartWindBot(command, "127.0.0.1", port, string.Empty, lockHand, 0));  // ② 玩家连本地
    }
}

public void StartWindBot(string command, string ip, string port, string password, bool lockHand, int delay)
{
    command = command.Replace("'", "\"");
    if (lockHand) command += " Hand=1";
    command += " Host=" + ip + " Port=" + port + " HostInfo=" + password;
    var args = Tools.SplitWithPreservedQuotes(command);
    // ... Dialog 回退逻辑 ...
    (new Thread(() => { Thread.Sleep(delay); WindBot.Program.Main(args); })).Start();  // ③ 进程内起 WindBot
}
```

**结论：本地人机 = 进程内 YGOPro 服务器 + 进程内 WindBot，走 127.0.0.1 本地 TCP。**
与"连远程服务器加 AI"是同一套协议模型，只是 host 换成本地、WindBot 换到进程内。

### 3.2 规则改写：`RDRule.lua`

`src/ygopro-rush-duel/script/RDRule.lua`

| RD 规则 | 实现方式 |
|---|---|
| 禁用最左/最右列 | `EFFECT_DISABLE_FIELD = 0x11711171` |
| 抽卡阶段抽到 5 张 | `EFFECT_DRAW_COUNT = max(1, 5 - 手牌数)` |
| 抽卡后洗切手卡 | `EVENT_DRAW` + `Duel.ShuffleHand` |
| 跳过准备阶段 | `EFFECT_SKIP_SP` |
| **召唤次数无限制** | `EFFECT_SET_SUMMON_COUNT_LIMIT = 100` |
| 场上怪兽效果强制 1 回合 1 次 | `EFFECT_CANNOT_ACTIVATE` + `EVENT_CHAIN_SOLVING` 打 `FLAG` |
| 同一时点只能发动 1 张陷阱 | `EVENT_CHAINING` + `Duel.SetChainLimit` |
| 无主要阶段 2 | `EFFECT_SKIP_M2` |
| 手牌无上限 | `EFFECT_HAND_LIMIT = 100` |
| 先攻也抽 1 张 | `EVENT_PHASE_START + PHASE_DRAW` → `Duel.Draw(0,1,REASON_RULE)` |
| 极大（Maximum） | `RushDuel.InitMaximum()` |
| "那之后"不打断时点 | 覆写 `Duel.BreakEffect` 为空函数 |

### 3.4 选择操作全部落到标准协议消息

`src/ygopro-rush-duel/script/RDFunction.lua`

```lua
function RushDuel.Select(hint, player, group, check, cancelable, min, max, ...)
    Duel.Hint(HINT_SELECTMSG, player, hint)
    if check == nil then
        if cancelable then return group:CancelableSelect(player, min, max, nil)
        else                return group:Select(player, min, max, nil) end
    else
        return group:SelectSubGroup(player, check, cancelable, min, max, ...)
    end
end
```

`group:SelectSubGroup` 是 ocgcore 标准 API → 产生标准
