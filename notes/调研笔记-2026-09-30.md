### 关键技术结论（可复用）
1. MDPro3 = Unity 客户端 + 内置 `ocgcore.dll`(C++) + 内置 `ygoserver.dll`(C++) + 内置 WindBot(C#)。
   源码在 `Tools/YGO Classes/ocgcore|ygoserver`，原生库在 `Assets/Plugins/Windows/`。
2. MDPro3 本地人机 = `SoloSelector.LaunchWithConfig` → `YgoServer.StartServer(args)` 起进程内服务器
   + 后台线程跑 `WindBot.Program.Main(args)`，两者走 127.0.0.1 本地 TCP。不是外部 WindBot.exe。
3. WindBot 的**牌组 AI 是 C#**（`Assets/Scripts/Windbot/Game/AI/Decks/*.cs`），不是 Lua。
   bot 列表 `Data/locales/<lang>/bot.conf`，牌组 `Data/Windbot/Decks/AI_*.ydk`。
4. 生态里另有一套 **Lua AI**：YGOPro Percy 的 `ai/ai.lua` + `ai/mod/*.lua` + `ai/decks/*.lua`。
   MDPro3 里对应入口是空壳：`Assets/Scripts/MDPro3/Duel/PercyOCG.cs → StartAI()` 被注释掉。
5. Rush Duel = 纯数据扩展 + 一条全局规则脚本。入口 `ygopro-rush-duel/script/special.lua`
   定义 `Auxiliary.PreloadUds()` → `RD.Init()`；`RDRule.lua` 用 EFFECT_* 全局效果改规则
   （召唤次数 100、抽到 5 张、无 SP/MP2、手牌无上限、极大召唤等）。
6. 触发点：`ygoserver/single_duel.cpp:578` 在 `YGOPRO_SERVER_MODE` 下**无条件**
   `preload_script(pduel, "./script/special.lua")`。
   脚本查找顺序 `data_manager.cpp: ScriptReaderEx`：`specials/` → `expansions/script/` → `script/`。
   卡库：`game.cpp: LoadExpansions()` → `./cdb/*.cdb`、`./Data/locales/zh-CN/*.cdb`、`./expansions/*.cdb`。
   ⇒ **装了 RD 扩展，本地人机就会变 RD，没有模式开关**（需做隔离）。
7. 本地服务器启动参数（`gframe.cpp:79-118` 逐位对照）：
   `port lflist rule mode arg5 arg6 arg7 lp hand draw time_limit replay_mode`
   MDPro3 传的是 `port -1 5 0 F F F lp hand draw 0 0`；`rule=5` 是**大师规则2020**，不是 RD 开关。
8. RD 的所有选择走标准协议消息（`RushDuel.Select` → `group:SelectSubGroup` → MSG_SELECT_CARD /
   MSG_SELECT_SUM），WindBot 已有 `OnSelectSum` / `OnSelectCard` / `OnSelectIdleCmd` 等通用回调
   ⇒ 协议层天然兼容，机器人不需要懂 RD 规则。
